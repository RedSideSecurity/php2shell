PHP2Shell Lab Setup

Four Docker containers, one per supported PHP branch, each on the last release before the CVE-2026-109618 / CVE-2026-109619 fix. Apache + mod_php (prefork), PHP default settings.

Lab only. These containers run intentionally vulnerable PHP. Bind them to 127.0.0.1 or an isolated network, never to a public interface, and remove them when done.

2. Prerequisites

  • Docker Engine 20+ on Linux (also works with Docker Desktop). Check with docker version.
  • curl for the verification steps.
  • About 2 GB of disk for the four images, and free local ports 8082–8085.
  • Docker Compose is not required; the scripts use plain docker build / docker run.

3. Create the files

If you already have the php2shell-lab/ folder, skip to step 4. Otherwise create this layout:

php2shell-lab/
├── run.sh
├── stop.sh
├── php-8.2/  Dockerfile  php2shell.ini  index.php
├── php-8.3/  Dockerfile  php2shell.ini  index.php
├── php-8.4/  Dockerfile  php2shell.ini  index.php
└── php-8.5/  Dockerfile  php2shell.ini  index.php

Dockerfile (one per folder)

Identical in each folder except the version in the FROM line and header comment: 8.2.34, 8.3.35, 8.4.26, 8.5.11. Example for 8.2:

php-8.2/Dockerfile
# PHP2Shell lab: PHP 8.2.34 (last release before the CVE-2026-109618/109619 fix in 8.2.x)
# Apache + mod_php (prefork) - the SAPI with confirmed RCE for both CVEs.
# LAB ONLY: intentionally vulnerable. Bind to 127.0.0.1, never expose publicly.
FROM php:8.2.34-apache

COPY php2shell.ini /usr/local/etc/php/conf.d/zz-php2shell.ini
COPY index.php /var/www/html/index.php

EXPOSE 80

php2shell.ini

Same for 8.2, 8.3 and 8.4:

php-8.2/php2shell.ini
; Minimum configuration for PHP2Shell exposure = PHP defaults, set explicitly.
file_uploads = On
memory_limit = 128M
post_max_size = 8M
upload_max_filesize = 2M
max_file_uploads = 20
max_input_vars = 1000
max_input_nesting_level = 64

; CVE-2026-109619 upload-progress path (default On, no session_start() needed)
session.upload_progress.enabled = On
session.upload_progress.cleanup = On
session.upload_progress.name = "PHP_SESSION_UPLOAD_PROGRESS"

index.php (same in every folder)

Prints the PHP version, the SAPI, the effective settings, and how many POST fields and files were parsed.

php-8.2/index.php
<?php
header('Content-Type: text/plain');
$keys = ['file_uploads', 'memory_limit', 'post_max_size', 'max_file_uploads',
         'max_input_vars', 'max_input_nesting_level', 'session.upload_progress.enabled'];
if (PHP_VERSION_ID >= 80500) $keys[] = 'fatal_error_backtraces';
echo "PHP_VERSION=" . PHP_VERSION . "\nSAPI=" . PHP_SAPI . "\n";
foreach ($keys as $k) echo "$k=" . var_export(ini_get($k), true) . "\n";
echo "method=" . $_SERVER['REQUEST_METHOD'] . " post_fields=" . count($_POST) . " files=" . count($_FILES) . "\n";

run.sh and stop.sh

run.sh
#!/bin/sh
# Build and start all four labs, bound to localhost only.
# 8.2 -> :8082, 8.3 -> :8083, 8.4 -> :8084, 8.5 -> :8085
cd "$(dirname "$0")"
for b in 8.2 8.3 8.4 8.5; do
  p=808${b#8.}
  docker build -q -t php2shell-lab:$b php-$b >/dev/null || exit 1
  docker rm -f php2shell-$b >/dev/null 2>&1
  docker run -d --name php2shell-$b -p 127.0.0.1:$p:80 php2shell-lab:$b >/dev/null && echo "php2shell-$b -> http://127.0.0.1:$p/"
done
stop.sh
#!/bin/sh
docker rm -f php2shell-8.2 php2shell-8.3 php2shell-8.4 php2shell-8.5
chmod +x run.sh stop.sh

5. Verify each container

5.1 Containers are up

docker ps --filter name=php2shell --format '{{.Names}}\t{{.Status}}\t{{.Ports}}'

Expect four rows, each Up … and bound to 127.0.0.1:808x->80/tcp.

5.2 Version and settings (GET)

for p in 8082 8083 8084 8085; do echo "== :$p"; curl -s http://127.0.0.1:$p/; done

Expected for each port (8.5 also shows fatal_error_backtraces='1'):

PHP_VERSION=8.2.34
SAPI=apache2handler
file_uploads='1'
memory_limit='128M'
post_max_size='8M'
max_file_uploads='20'
max_input_vars='1000'
max_input_nesting_level='64'
session.upload_progress.enabled='1'
method=GET post_fields=0 files=0

5.3 Multipart parsing (harmless POST)

Sends one upload-progress field, one normal field and a tiny file. This exercises the multipart code path both CVEs sit in, without triggering anything.

echo test > /tmp/t.txt
for p in 8082 8083 8084 8085; do
  printf ":$p  "
  curl -s -F PHP_SESSION_UPLOAD_PROGRESS=lab -F field=1 -F f=@/tmp/t.txt http://127.0.0.1:$p/ | tail -1
done

Expected on every port: method=POST post_fields=2 files=1

5.4 SAPI and Apache MPM

for b in 8.2 8.3 8.4 8.5; do printf "$b  "; docker exec php2shell-$b apachectl -V 2>/dev/null | grep 'Server MPM'; done

Expected: Server MPM: prefork for all four. With SAPI=apache2handler from 5.2, this confirms mod_php on prefork.

6. Optional: patched and mitigated comparisons

Useful as a control when testing detection rules or WAF signatures: same setup, one variable changed.

Patched control

Build the same folder on the fixed release. Example for 8.3 on port 9083:

sed 's/php:8.3.35-apache/php:8.3.36-apache/' php-8.3/Dockerfile > php-8.3/Dockerfile.patched
docker build -t php2shell-lab:8.3-patched -f php-8.3/Dockerfile.patched php-8.3
docker run -d --name php2shell-8.3-patched -p 127.0.0.1:9083:80 php2shell-lab:8.3-patched
curl -s http://127.0.0.1:9083/ | head -1     # PHP_VERSION=8.3.36

Fixed tags: 8.2.35, 8.3.36, 8.4.27, 8.5.12.

Mitigated control (vulnerable version, workaround settings)

Overrides the ini at run time with the advisory workarounds. These reduce but do not remove exposure.

cat > /tmp/mitigate.ini <<'EOF'
session.upload_progress.enabled = Off
fatal_error_backtraces = Off
EOF
docker run -d --name php2shell-8.5-mitigated -p 127.0.0.1:9085:80 \
  -v /tmp/mitigate.ini:/usr/local/etc/php/conf.d/zzz-mitigate.ini:ro php2shell-lab:8.5
curl -s http://127.0.0.1:9085/ | grep -E 'upload_progress|backtraces'   # both '0' or ''

7. Troubleshooting

SymptomFix
port is already allocatedAnother service uses 808x. Change the host port in run.sh (-p 127.0.0.1:NEWPORT:80).
manifest unknown on buildThe image tag was removed from Docker Hub. Pull it from a mirror, or build PHP from source at that version.
curl: (7) Failed to connectContainer exited. Check docker logs php2shell-8.x.
Settings differ from section 1The ini was not copied. Rebuild without cache: docker build --no-cache …
Need access from another VMBind to that isolated network's interface IP instead of 127.0.0.1. Never 0.0.0.0 on an internet-facing host.
